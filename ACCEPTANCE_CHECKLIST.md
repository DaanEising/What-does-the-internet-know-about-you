# Acceptance Checklist

## Essential (must pass before class)
- [ ] Site launches locally and via browser preview with no broken fonts/assets and no API keys.
- [ ] English explainer only; optional Dutch developer notes are not shown to the audience.
- [ ] Total timeline is **exactly 120,000 ms**, with nine non-overlapping scenes.
- [ ] Play, pause, replay and seek work; playback state does not drift when tab is hidden or user pauses.
- [ ] First launch offers an obvious **Start explainer** button (autoplay audio may be blocked by the browser).
- [ ] All researched numbers use the correct population, country, year, and cited source.
- [ ] `9.2 years` is not labelled average for all Dutch children regardless of phone ownership.
- [ ] `10 years 3 months` identified as Flanders, not Netherlands.
- [ ] Distinct color/shape/legend for observed data, inferred possibilities and recommendations.
- [ ] No fabricated quantities of data collected or pseudo-statistical "profile completeness" scores.
- [ ] No insinuation of an actual unified database across Google, Meta, TikTok, etc.
- [ ] Explicitly hypothetical “interest in running” inference.
- [ ] Clear DSA minors advertising nuance in Methods panel.
- [ ] Scrolling and resizing don't break classroom 16:9 presentation; no horizontal overflow.
- [ ] Source links open and remain usable (external pages require internet, playback does not).
- [ ] Text readable from classroom back row; contrast and keyboard controls checked.
- [ ] `npm install`, `npm run build` and `npm run dev` work without build errors.
- [ ] At least one manual full 2:00 playback test on target browser/projector.

## Nice to have (only after essential)
- [ ] Optional voice-over with closed captions.
- [ ] Subtitle toggle.
- [ ] Reduced-motion support.
- [ ] One-click fullscreen mode.
- [ ] Downloadable screencast backup if internet/cloud preview fails.

## Presenter's 30-second introduction (English, optional)
"We built a two-minute interactive explainer about a digital footprint across childhood and adolescence. The person is fictional, while the statistics come from published media-use research. We separate what services observe from what they might infer about someone."
